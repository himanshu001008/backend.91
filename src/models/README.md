# FlexFit Database Models Directory

This directory will hold Mongoose database schemas and models for the FlexFit platform.

Future models to be implemented:
- `User.js` - User schema (Admin, Trainer, Member)
- `Class.js` - Fitness Class schema (Title, Capacity, Schedule, Trainer)
- `Booking.js` - Class Booking schema (User ID, Class ID, Payment Status, Booking Time)
